기준 문서

ms-settings URI 모음. 기준 문서: Microsoft Learn Launch Windows Settings (2026-09-26 갱신본). Windows에서 열어야 동작합니다.

URI는 이렇게 생겼습니다

ms-settings:카테고리-페이지?파라미터

예: ms-settings:privacy-webcam 개인정보 › 카메라 · ms-settings:defaultapps?registeredAppUser=앱이름 특정 앱의 기본 앱 설정 · ms-settings:appsfeatures-app?<PFN> 앱 고급 옵션. 예외로 ms-windows-store:, windowsdefender:처럼 별도 프로토콜을 쓰는 항목도 있습니다.
