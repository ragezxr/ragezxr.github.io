ℹ 도움말

상단 버튼이나 옵션을 통해 모든 연산 요소를 자유롭게 제어할 수 있습니다. 수식 입력 후 Enter를 누르면 결과가 즉시 출력되며 복사 시 결과와 서식이 유지됩니다.

• 🔢 Layer 2 확장 예제 칠판: Layer 1의 숫자/기본연산 버튼을 반복하지 않고 ƒx 함수 목록의 전체 항목을 실제 계산 예제로 보여 줍니다. 화면이 좁으면 1열, 넓어지면 여러 열로 자동 확장되고 칠판 내부만 세로 스크롤됩니다.
• 💡 Layer 2 보기: 첫 줄의 탭에서 전체보기 또는 원하는 분류를 바로 선택하고, 아래 예제 카드는 화면 폭에 맞춰 자동으로 열 수가 조절됩니다.
• 🛡️ 입력 안전성: eval/Function 등의 임의 코드 실행을 사용하지 않는 제한형 파서이며, 0 나눗셈·비정상 결과·잘못된 금융/통계 인자 등은 해당 줄만 오류 처리합니다.
• → 순차연산 SEQ(Sequential): [일반 계산기 / 표준 모드] 입력된 순서대로(사칙연산 우선순위를 무시) 앞에서부터 처리(5 + 5 * 5 = 50)
• fx 사칙연산 ALG(Algebraic): [공학 계산기 / 일반 수학] 수학적 우선순위(괄호 > 곱셈·나눗셈 > 덧셈·뺄셈) 먼저 처리(5 + 5 * 5 = 30)
• 단축키: Enter(다음 줄) | Ctrl+Z(실행취소) | Ctrl+Y(재실행) | Ctrl+Shift+C(복사)
🔢 숫자패드 배열·높이 · 상단 🔢 또는 숫자패드 Enter를 길게 누르면 4x6·4x8·5x6 배열을 고를 수 있습니다. 숫자패드 맨 위 얇은 선을 위아래로 끌면 높이를 조절합니다. 설정 초기화·전체 초기화를 하면 얇은 4x8과 기본 높이로 돌아옵니다(🔒 UI 설정 보호를 켜면 유지).
• 길게 누르기: ↶ ↷ ⌫ 는 실행취소·재실행 묶음(×3 ×2 ×1), CE는 🚨 🧹 ⌫, Enter는 상단 메뉴 아이콘 모음, 📚는 기호 선택 팝업을 한 단계로 표시합니다.

📐 단위변환 모드 · 상단 메뉴의 📐 아이콘을 누르면 전체화면 단위변환(길이·넓이·무게·부피·온도·압력·속도·연비·데이터·시간)이 열립니다. 제목 오른쪽 끝의 ✕ 또는 Esc로 닫으면 계산기로 돌아오며 숫자패드가 켜집니다.

📏 단위 표기 · 숫자 뒤에 단위를 붙이면 자동으로 합산됩니다: 길이 km·m·cm·mm(m 기준), 무게 kg·g(g 기준), 부피 l·ml(l 기준), 시간 h·min·s(분 기준). 예) 1m+50cm, 2l+500ml, 1h+30min+45s

🎛️ UI 옵션 도움말
• 전체 비율: UI 세부사항의 모든 폰트 크기(입력·수식목록·숫자패드·메뉴·합계바·팝업·옵션창)에 한꺼번에 곱해집니다. 비율을 바꾸면 세부사항의 숫자도 함께 바뀝니다.
• UI 세부사항: 숫자는 화면에 실제로 적용되는 px입니다. 직접 입력, ▲▼(누르고 있으면 반복), 마우스 휠(±1px)로 조절하고 칸을 비우면 기본값입니다. B에 체크하면 해당 글자가 굵게 표시되고, 기본이 굵은 항목은 체크 해제 시 보통 굵기가 됩니다.
• 숫자패드 팝업: 숫자패드 버튼 모서리에 점(●)이 있으면 지정한 지연시간 후 팝업이 열리고, 누른 채 상하좌우로 자유롭게 밀어 선택할 수 있습니다. 1~4열은 왼쪽에서 시작해 오른쪽 끝 ✕에서 취소하고, 5~8열은 오른쪽에서 시작해 왼쪽 끝 ✕에서 취소합니다. 이동 민감도와 지연시간은 UI 전체 제어에서 조절합니다.
• UI 설정 보호: 켜 두면 설정 초기화와 전체 초기화를 해도 UI 전체 제어·UI 세부사항의 모든 설정이 유지됩니다.
• 설정 초기화: 전체 비율·줄 간격·상태창 글자색·세부 폰트 크기·굵기·숫자패드 팝업 이동 민감도·지연시간·웹폰트를 기본값으로 되돌립니다(진동 설정은 유지).
• UI 복사 / 붙여넣기: 현재 UI 설정을 텍스트로 복사해 두었다가 다른 기기·브라우저에서 붙여넣어 같은 설정을 적용합니다.
